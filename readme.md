# WHO Global Status Report on Dementia (2021) — Analytical Intelligence Dashboard

This is an analytical, data-visualization dashboard based on the official World Health Organization publication:
* **Title:** Global status report on the public health response to dementia (2021)
* **ISBN:** 978-92-4-003324-5
* **Publisher:** World Health Organization

[Open the live dashboard](https://shubhanginidixit.github.io/dashboard/)

## Purpose
This dashboard provides research-grade, academic, and policy intelligence on:
1. Global dementia epidemiology and future projections.
2. Direct and indirect economic societal costs.
3. Gender inequalities and informal caregiving burden.
4. Diagnostic gaps and health system equity disparities between HICs and LMICs.
5. Risk factor reduction strategies and illustrative delay scenarios.
6. The Global Dementia Observatory (GDO) database (62 Member States).
7. Progress across the 7 action areas of the Global Dementia Action Plan (2017–2025).

## Getting Started

No build system or Node.js environment is required.

1. Clone or extract the `dementia-dashboard` folder.
2. Open `index.html` directly in any modern web browser.

## Data Methodology & Compliance
* **Observed / Baseline Data:** Sourced directly from WHO 2019 baseline estimates.
* **Projections:** Based on standard UN population demographic projections with constant age-specific prevalence rates.
* **Cost Adjustments:** $2.8 Trillion figure incorporates WHO real-wage growth care cost adjustments.
* **Simulations:** The Risk Reduction Delay Slider explicitly represents an illustrative scenario calculation rather than a forecast.
